# Quantum web

> The quantum web is the Tyrer Framework's image of generated interfaces: in superposition until an observer arrives, then collapsing into the rendering that observer needs.

**Real.** This entry is about something real, written from outside the CharliVerse.

The **quantum web** is an analogy from the [Tyrer Framework](https://charli.info/charlipedia/tyrer-framework/). The web [classical accessibility](https://charli.info/charlipedia/classical-accessibility/) was built for was Newtonian: fixed objects at known positions, obeying predictable rules. The web now emerging is quantum: an interface exists in superposition until an observer arrives, then collapses into a particular rendering shaped by context and capability.

The interface a sighted user sees is one collapse of the underlying data. The one a blind user receives is another. The one an AI agent consumes is a third. "None is the original and none is the adaptation." That is the structural definition of Type I on the [Tyrer Accessibility Scale](https://charli.info/charlipedia/tyrer-accessibility-scale/), and the world [generative accessibility](https://charli.info/charlipedia/generative-accessibility/) works in. Its safeguard is the [Right to Inspect](https://charli.info/charlipedia/right-to-inspect/): the right to demand a different collapse.
