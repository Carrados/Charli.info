Runs

Canon. This entry is written from inside the CharliVerse, so its people and companies are fictional. Behind the scenes says what is real.

Runs are the limited editions of Iceberg Hosiery and Seamiotics. They are named, on purpose, after the one word a hosiery house is supposed to fear. A run is the ladder you dread; a run is the batch you queue for. The house reclaims its worst word as its rarest: the defect becomes the edition.

A run breaks one law, in one direction, for one reader.

The law counts directions, not properties. A Run may change several things at once, provided they all say the same thing louder. If it breaks in every direction, it is not a run; it is a fault.

Runs happen when there is a piece worth making. There is no quota, no monthly novelty and no seasonal slot to fill. A Run costs sixty-five pounds, because an edition is a different kind of purchase, not a dearer version of the same one.

Iceberg's Runs

Prints on Polar white, in the season's weight and never lighter, so the image holds under stretch. They are public: the parent has no private register. The first is Polar Solstice; a holiday print is being explored.

Seamiotics' Runs

Red seams and red fishnets, below the hem, addressed to the room: the Red Pen. Every Run is offered in both welts, because the welt belongs to the wearer, not to the edition.

Behind the scenes

Runs are set out in the House of Iceberg Bible, version 7, and the Seamiotics Bible, version 1.4. Laddering itself, the real thing, is still an open commercial question for both houses.
