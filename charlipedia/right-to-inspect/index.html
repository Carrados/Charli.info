Right to Inspect

Real. This entry is about something real, written from outside the CharliVerse.

The Right to Inspect is the founding governance principle of generative accessibility: no user should be required to accept a generated interpretation they cannot interrogate.

When interfaces are generated, they can't be audited like fixed pages; what can be governed is the system that generates them. So:

  • if a system produces a summary, the user can ask for the underlying data;
  • if it renders a simplified view, the user can ask for the full complexity;
  • if it collapses the interface into one modality, the user can demand another.

The principle isn't only for disabled people. In an AI-mediated world, the tools accessibility needs, inspecting the source, verifying the state, controlling the rendering, become safeguards for everyone. "Accessibility governance becomes information governance. The sidecar becomes the chassis."
