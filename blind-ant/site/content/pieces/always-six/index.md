## About the Piece

Always Six is a very short cartoon, and the record of how it was made. It was directed by Charlotte Joanne, and painted in code by Claude.

The cartoon is painted in code, frame by frame, by brush-stroke software. It was storyboarded as a list of timed moments: what the viewer must understand, and when. Those moments are an audio description script written before anything was drawn. So here they are the single source of truth, and the picture and the description are built from the same lines.
